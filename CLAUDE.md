# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Викторины для подготовки к экзамену Celpe-Bras (сертификат владения бразильским португальским): виды текстов, артикли, предлоги, акценты, вводные конструкции. Пользователь один, работа делится примерно так: логики мало, контента много — основное занятие здесь редактирование вопросов в `data/`, а не правка кода.

## Команды

```bash
node tools/validate.mjs
```

Валидатор `data/`: непустой `sections.json`, читаемость файлов разделов, уникальные `id` разделов и вопросов, непустой `explanation`, `answer` в границах `options`, отсутствие дублей среди вариантов и среди `prompt`. Обязателен перед любым коммитом, трогающим `data/`.

```bash
node --test
```

Тесты `assets/engine.js` (встроенный тест-раннер Node, без зависимостей). Один тест — `node --test --test-name-pattern "повторный ответ"`.

Локальный сервер (открывать `index.html` с `file://` нельзя — см. ниже):

```bash
npx serve
```

```bash
python -m http.server 3000
```

## Архитектура

Статический сайт: HTML + ES-модули + CSS. Ни сборки, ни npm, ни `package.json`, ни CI, ни внешних ресурсов (шрифтов, CSS-фреймворков). Node нужен только для валидатора и тестов; в браузере он не участвует. Это осознанное решение из [дизайн-спеки](docs/superpowers/specs/2026-08-11-celpe-bras-quiz-design.md) — не добавлять сборку, зависимости и внешние подключения без явной просьбы.

Две страницы обслуживают все разделы: `index.html` (список разделов) и `quiz.html?s=<sectionId>` (универсальная викторина). Новый раздел = JSON в `data/` + строка в `data/sections.json`. HTML и JS при этом не трогаются.

Слои в `assets/`:

- `engine.js` — чистая логика (перемешивание, сессия прохождения). Ни DOM, ни `localStorage`. `random` передаётся параметром, поэтому логика тестируема. Единственный протестированный модуль.
- `data.js` — загрузка JSON, `DataError` с человеческими сообщениями.
- `storage.js` — прогресс в `localStorage`, ключ `celpe:<sectionId>`. Все обращения обёрнуты в try/catch: недоступное хранилище (приватный режим) не должно ломать прохождение.
- `index-page.js`, `quiz-page.js` — рендер. DOM собирается через `createElement`/`textContent`, без `innerHTML`.

### Инварианты, которые легко нарушить

- **Правильность варианта — свойство самого варианта, а не индекс.** `prepareQuestions` превращает `options: string[]` + `answer: number` в `options: {text, correct}[]`, после чего индекс из JSON нигде не используется. Иначе перемешивание молча засчитывает не тот ответ. Это и есть причина, по которой `engine.js` покрыт тестами.
- **`id` существующего вопроса менять нельзя** — к нему привязана статистика в `localStorage` пользователя.
- **`file://` не работает по-настоящему**: у документа непрозрачное происхождение, поэтому `<script type="module">` не запускается вообще. Сообщение об этом показывает отдельный классический инлайн-скрипт в `<body>` каждой страницы — он один и тот же в `index.html` и `quiz.html`, тексты обеих копий должны совпадать дословно (и с текстом ветки `file:` в `data.js`).
- **Один битый JSON не должен уносить страницу.** Главная грузит разделы через `Promise.allSettled` и рисует упавшему разделу карточку без ссылки.

## Формат вопроса

```json
{
  "id": "art-009",
  "prompt": "___ Japão fica na Ásia.",
  "options": ["O", "A", "Os", "—"],
  "answer": 0,
  "explanation": "Страны обычно с артиклем: o Japão, o Brasil, a França.",
  "tags": ["países"]
}
```

`answer` — индекс с нуля в исходном (неперемешанном) массиве. `explanation` обязателен: викторина без объяснения проверяет, но не учит. Пропуск в `prompt` — `___`. Переносы строк внутри варианта допустимы (рендерятся через `white-space: pre-line`). `tags` необязательны.

Поддерживается ровно один тип вопроса — выбор одного варианта. Ввода текста нет.

## Оформление

Mobile-first, одна колонка, `max-width: 40rem`, системный шрифт, палитра в CSS-переменных `:root` + `prefers-color-scheme: dark`. Состояния ответа различимы не только цветом (галочка/крестик + рамка). Анимации отключаются при `prefers-reduced-motion`. Клавиатура: цифры выбирают вариант, Enter/пробел листают дальше — но обработчик не перехватывает клавишу, если фокус стоит на ссылке или кнопке.
